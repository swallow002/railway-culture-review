# 16项目学习评价网页

打开 index.html 查看项目列表。每个项目包含情境判断、排序或关联练习，以及选填的自我反思；作答后显示反馈。通过项目列表可获得各项目独立链接（例如 index.html?project=10），部署后可将相应链接放入课程。

网页不收集或保存答题数据，刷新后可重新练习，选填的反思内容也会清空；题目是自主练习，不会自动计入学习通成绩。涉及岗位安全的题目用于学习讨论，实际工作应遵循岗位规定和现场安排。

## 发布与使用

1. 将网站文件放在公开仓库的根目录：`index.html`、`style.css`、`data.js`、`activities.js`、`app.js`。请保持文件名不变。
2. 在仓库 Settings → Pages 中选择从分支发布，并选择包含这些文件的分支及根目录，保存后等待发布完成。
3. 打开 Pages 提供的实际地址，逐个检查项目入口，再将对应项目的链接加入学习通。项目链接格式为主页地址后加 `?project=项目编号`，例如项目 10 使用 `?project=10`。

上传到 GitHub 不等于网页已经发布；只有 Pages 显示发布完成、实际链接能够访问后，才能将其发给学生。当前练习不要求登录，也不保存成绩。
